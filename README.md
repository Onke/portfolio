# Onke Sipuka - Portfolio

This repository contains a brand-new portfolio experience built from scratch with the latest React + Vite toolchain. It highlights work across insurance, fintech, and product strategy with modern routing, responsive layouts, and data-driven content.

## Tech stack

- React 19 with functional components and hooks
- React Router for routing and scroll restoration
- Vite 7 for dev/build tooling
- Modern CSS (custom properties, fluid typography, responsive grids)

## Getting started

```bash
npm install
npm run dev      # start local development server
npm run build    # create a production build
npm run preview  # preview the production build locally
```

> **Note:** Vite 7 requires Node.js 20.19+ (or Node 22). Upgrade your local runtime if you see `EBADENGINE` warnings during `npm install`.
